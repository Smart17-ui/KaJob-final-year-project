# KaJob

A full-stack job marketplace connecting employers and job seekers, built as a final-year Software Engineering project.

## Tech Stack
- **Backend:** Django REST Framework, PostgreSQL, JWT authentication
- **Frontend:** [React / Vue / whatever you used]

## Key Features
- 30+ REST endpoints covering the full job lifecycle (post, apply, accept, complete, review)
- Two-layer permissions system with JWT-based role-switching for dual-role users
- Atomic database transactions to prevent race conditions in concurrent "accept application" flows
- Role-filtered notification system with in-app, email, and real-time channels
- 5km job broadcast radius for local job discovery
